<h1>TareasYa – APP de Lista de Tareas con Categorías</h1>

## 📝 Descripción del Proyecto
Es una aplicación diseñada para ayudar a los usuarios a organizar y gestionar sus actividades
diarias de manera más efectiva. Permite que los usuarios creen tareas y las clasifiquen en categorías.
Esto facilita el seguimiento, la priorización y mejora la productividad, ya que el usuario
puede enfocarse en lo que realmente importa en cada momento.

## 🎯 Objetivo del Proyecto
El objetivo es ofrecer una aplicación sencilla pero completa para que cualquier usuario pueda:

- Organizar sus actividades
- Tener recordatorios claros
- Clasificar su vida en categorías
- Cumplir sus tareas con mayor facilidad
- Dividir tareas grandes mediante subtareas

## 📌 Alcance del Proyecto

El proyecto consiste en una aplicación móvil que permite a los usuarios organizar sus actividades mediante tareas,
subtareas y categorías. Incluye registro de usuarios, creación y gestión de categorías, administración de tareas 
con fecha límite, prioridad y recordatorios, así como manejo de subtareas.  
La información se almacena mediante una API conectada a una base de datos, garantizando orden, control y fácil 
acceso a las actividades del usuario.

## 🛠 Tecnologías Utilizadas

- **Android Studio**: Entorno de desarrollo para la creación de la aplicación móvil.
- **Java**: Lenguaje de programación utilizado en la lógica y vistas de la app.
- **Node.js**: Plataforma utilizada para construir el backend.
- **Express.js**: Framework para manejo de rutas y API dentro de Node.js.
- **PostgreSQL**: Base de datos donde se almacenan usuarios, categorías, tareas y subtareas.
- **Retrofit**: Librería usada para realizar las peticiones HTTP desde la app al backend.


## 🏗 Estructura de la Base de Datos
La base de datos está compuesta por 4 tablas principales:

### 👤 **Usuario**
Almacena los datos personales del usuario y controla su acceso.

### 🗂 **Categorias**
Organiza las tareas en grupos personalizados por cada usuario.

### 📝 **Tareas**
Guarda la información principal de cada tarea como título,
descripción, fecha límite, prioridad, etc.

### ✔️ **Subtareas**
Permite desglosar cada tarea en pasos más pequeños.
